# 🌿 Paradise Nursery - Plant Shopping App

A modern e-commerce web application for purchasing houseplants, built with React and Redux.

## Project Overview

Paradise Nursery is a fully functional plant shopping application that allows users to browse a variety of houseplants, add them to a shopping cart, and manage their purchases. The app features a clean, responsive design with real-time cart updates.

## Features

- **Product Listing**: Browse plants organized by categories
- **Shopping Cart**: Add/remove items, update quantities
- **Category Filtering**: View plants by category
- **Cart Management**: Increase/decrease quantities, remove items
- **Redux State Management**: Centralized state with Redux Toolkit
- **Responsive Design**: Works on all screen sizes

## Technologies Used

- React 18+
- Redux Toolkit
- React Router DOM v6
- CSS3
- Font Awesome Icons
